# 东亚美型角色设计技能

给出一个模糊的气质、身份或想法，让AI实际查看参考图，设计五官外貌、发型、穿搭、配饰和配色，最终交付完整可复制的绘图提示词。

**最高准则：好看，男帅女美。** 以用户认可的当代东亚主流明星与模特审美为参照，覆盖现代、古代、仙侠与玄幻。默认只求好看且符合身份气质；明确要求辨识度时，再在美感上设计特色。后期渲染风格由使用者自行添加。

## 用链接安装

把本仓库链接发给支持读取GitHub和安装本地技能的AI助手，并说：

> 请帮我安装这个仓库里的角色设计技能：安装路径是 skills/gufeng-character-designer。请先阅读 INSTALL.md，保留技能说明、references、assets、预览与图库索引等完整资源。安装后告诉我调用方式。

Codex也可以使用内置 `$skill-installer`，让它安装本仓库的 `skills/gufeng-character-designer`。本技能采用包含 `SKILL.md` 的目录形式，不绑定账号、电脑或创建时的聊天记录。

其他支持Agent Skills格式的工具可按其本地技能目录安装。同一份内容也可作为工作指令使用；仅有文字聊天、无法联网或读写文件的产品，不能仅凭链接完成本地安装。安装能力取决于目标工具，而非使用哪种语言交流。

## 调用示例

> 使用 $gufeng-character-designer，帮我设计一位温润的年轻世家公子。先按技能流程收敛人物想法，最后交付详细外观提示词。

图片和索引随技能一起提供，运行路径均相对于技能目录。本机原始路径已替换为来源标签。每次设计前必须重新逐张查看全库原图；联系表与交叉分类只用于导航。

技能会在用户明确选择后交付最终词；默认候选结构来自原模板，可按当次需求减少。完整规则见 [SKILL.md](skills/gufeng-character-designer/SKILL.md)。

参考图片用于观察外形、搭配和配色，相关作品与人物照片的权利归各自权利人。这里的整理不额外授予第三方图片的授权。提示词设计采用提取与融合关系的方式。


当前修订：2026-10-30-r5。每次设计前必须重新逐张查看全库参考原图，记录查看情况，结合娃娃/真人五官妆面、发型及插画配色方法重新设计；一图多用，不限制两三种颜色。已安装旧版时需更新技能与配套资料。审美验证仍在迭代，不能将规则更新视为已经稳定达到用户标准。
