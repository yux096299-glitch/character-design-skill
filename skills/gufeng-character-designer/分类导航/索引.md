# 资料库交叉分类导航

分类用于查找，不改变原始图的存放位置，不重复存图。同一张图可同时属于古风、娃娃、发型、服装与配色等多个分类。二维、真人感、AI/CG等标签是视觉导航，不保证鉴定作品的制作来源或人物身份；存在不清楚的内容，设计前打开原图核对。联系表视觉初分不等于已查看全部原图，每次设计仍须按强制规则逐张查看全库。

长相与妆容无论古风、现代还是真人方向，均可先比较娃娃参考；娃娃中缺少相应气质或需要换方向，再结合明星、真人、AI合成人像及其他清楚露脸图片。衣服与配色重点查看古风服装和插画，现代衣服参考不足，不默认具备现代服饰设计能力。
