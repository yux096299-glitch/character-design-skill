# 把设计写成简短、可复制的提示词

先按 [沟通与交付.md](沟通与交付.md) 确认新角色或旧角色重做、头部或整套、男性耳饰选择，再根据本轮实际查阅的参考设计。不要用固定脸型模板替所有角色作决定。

默认每版一个自然短段落，不固定六段，不留空栏目。以用户给定的年龄、身份、美感和气质自然开头，例如“一位二十岁、清俊秀雅的少年星君，气质温润端方”。内部审美标签不机械写进开头；年龄未知且影响设计时先问，不把例子的二十岁当默认年龄。

依次描述脸型轮廓、眉眼、鼻唇与肤质，再接发型、发饰和允许的耳饰。用清楚、普通的可视化词，不写解剖报告、测量数据或长篇设计解释。三庭五眼用于观察协调关系，不要求模型解算虚构比例。妆面按实际参考形成适合角色的修饰，必要时一句交代，男性不默认浓妆。

只做头部时到这里结束，不添加衣服、项链、身体饰品或服装色卡。整套模式再用几句写一套衣服的款式、面料、层次、颜色及关键装饰；简洁不等于只写“纱衣”。参考 [服装款式与直白描述.md](服装款式与直白描述.md)。

每个特征绑定具体部位，同一部位只留选定方案，删除互斥描述、同义词堆积和无关负面清单。写全本版必要内容，不依赖“同上”“如参考”“像某明星”或A/B备选项。瞳色只在用户主动要求时出现。

默认三版不同长相，用户指定数量则遵从。旧角色重做也按最新提示词重新设计脸，不自动逐字复用旧脸；用户明确要保留脸、仅改发型或补衣服等局部任务时，以其指定范围为准。

素材按 [资源复用规则.md](资源复用规则.md) 提取或组合，图号用于内部追溯，不代替可见描述。美貌为先，温柔不自动等于幼态圆软，清冷不自动等于尖瘦；只在用户要求时额外强调辨识度。

后期风格、渲染、灯光与模型参数由用户处理。默认只输出提示词，不自动生图；没有实际验证就不声称验证成功。
