# 把人物设计编译成AI绘图提示词

## 依据与适用范围

查阅日期：2026-10-30。以下写法参考OpenAI公开文档，再针对本技能只交付人物外观的用途做取舍。文档支持的是表达清楚、指令有结构和保持关键特征的方法，并未证明某组词能保证所有模型画出大众认可的美貌。

- [Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)：明确主体和约束；延续同一角色时复用其外貌、比例等识别特征。
- [ChatGPT Learn：Image generation](https://learn.chatgpt.com/docs/image-generation)：用具体可见的语言表达需求，多图时说明各自提供什么内容，修改时明确改变与保留的部分。
- [OpenAI Cookbook：GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)：该页面已归档，仅借鉴其通用写法：目标清楚、组织一致、形状与材质具体，复杂内容可分段；不是越复杂的语法越好。

美貌优先、东亚主流明星模特方向，以及头部先于服装，是用户的默认设计要求；特色只在用户明确提出时增加。下面的具体编译规则是本技能据此形成的工作方法，不冒充官方审美标准或私人用户数据统计。

## 编译方法

先完成协调的人物设计，再把它写成自然语言提示词。不要一边堆标签一边指望生图模型替你解决五官冲突。

1. **保留美貌目标**：开头明确人物年龄感、东亚长相及帅或美的目标。允许写“俊美”“明艳漂亮”等，不因追求客观描述删去美貌要求；随后用结构支持，不能只停留在赞美词。
2. **把整张脸组织起来**：按“脸型与轮廓 → 眉眼布局 → 鼻唇衔接 → 颧颌和肤色”的关系写，不是把每个器官单独堆到最尖、最大、最高。三庭五眼用于设计分析，最终转成可见的长短、宽窄、间距与轮廓，不要求绘图模型解算未测量的小数或黄金比例。
3. **写清好看的搭配**：默认明确协调的眉眼、鼻唇、轮廓和发型关系，不额外要求不大众脸，也不为避开相似长相改坏五官。用户明确要求特色时，才选择相互支持的识别特征，写入对应部位；不自动靠伤疤、异色瞳或巨饰制造差异。
4. **修饰词绑定部位**：明确什么是修长、圆润、柔和、凌厉，什么颜色属于瞳孔、头发、外衫、内层或边饰。少用悬空形容词，避免一个颜色或形状被误用到全身。
5. **细节完整而不打架**：同一部位采用一个明确方案，删除备选、重复同义词及互斥要求。没有实际作用的细节不硬塞，但保留用户指定和设计必需的信息。详细不等于反复夸赞或写满参数。
6. **用正面目标表达造型**：直接写“下颌线清楚、下巴自然收束”，而不把“不方、不圆、不要太尖”串成主体描述。确有必要的排除项简短、具体；不生成一长串与本角色无关的负面词。
7. **输出可独立使用**：默认中文自然语言，可分【长相】【服装】两段，也可合成完整段落。最终版本写全确认内容，不含“同上”“参考某明星即可”“方案A或B”。未知平台不编造权重、括号语法、参数或所谓通用必胜词。
8. **复用身份锚点**：换衣服时逐字复用已经确认的核心长相描述，只改有关部分；不每次换一套近义词重写整张脸。用户以后提供生成图再按可见偏差定点改词，不能把未出图的文本检查称为实测有效。

参考角色的美貌与特征可以融合，文件夹不限制用途。图号只用于设计说明与索引；用户未将图片交给生图工具时，最终提示词须写出图中已经提取的具体内容，不靠本地编号传达长相。

## 默认美感与按需辨识度

默认交付脸美、造型好看且符合身份气质的完整外观，不额外设“不大众脸”门槛。用户提出辨识度要求时，在现有美感上选取适合人物的可见变化，并同步调整搭配；辨识度不能通过牺牲美貌获得。

编译时体现变化所在，例如眉眼组合、修饰轮廓的鬓发或呼应身份的衣领层次，不能只添加“独特、有辨识度”几个词。每个识别点仍要融入整张脸与整体造型，不把“更加不同”当作“更加好看”的替代。现代、古代、仙侠、玄幻均按同一美感优先级执行。

## 编译示意

以下只是说明表达方法，不是所有人物的固定脸型。

笼统输入：“温润贵公子，特别帅。”

可绘制的长相写法：“二十五岁左右的俊美东亚男性，面部清俊，脸型修长，额头与颧部过渡平顺，下颌线清晰，下巴自然收束；深色长眉舒展，眉峰平缓，眼形修长、眼尾略扬，深棕色瞳孔，上眼睑线条清楚，眉眼间距舒展；鼻梁直而不过分突兀，鼻头收得干净，上唇偏薄、唇峰清楚，下唇略丰，唇角自然平直。黑发半束，额前偏分的两缕长鬓发沿颧侧垂下，后发顺直。”

这段的作用是把目标落实为可见关系，不表示这些五官组合具有统计上的普遍最优性。这是可用的美型组合之一，不作为其他角色的固定模板，也不要求为了差异避开类似的好看组合。
