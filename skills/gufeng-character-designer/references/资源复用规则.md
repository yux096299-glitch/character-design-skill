# 资源复用权限（以此为准）

用户允许图库资源直接复用、识图提取与组合，不要求每个部位重新发明。每轮仍先问清关键人设、完成全库逐图查看，再选择符合身份气质且好看的资源。以下权限替代旧版笼统禁止复制、禁止识图复述、要求所有部位原创或要求每张脸都改动的限制。

| 资源 | 允许的用法 |
| --- | --- |
| 娃娃的脸与妆面 | 允许直接识图分析、提取具体长相与妆容，转为可用于本角色的提示词，不强制改脸。 |
| 二维插画的脸与妆面 | 同样允许直接识图提取长相。插画也有可用的五官布局和面容，不能因不如真人可实化就排除。 |
| 真人/明星、AI生成或合成的人物脸 | 允许大幅参考其五官布局、轮廓与气质框架，但不允许完全复制整张脸；保留新的面部差异。用户所说“可参考80%”是接近程度的口语尺度，不编造相似度测量。只换发型、衣服或颜色而脸完全一样，不满足这条。 |
| 发型 | 所有来源均允许一比一复刻；选择适合本角色的发型即可，不强制改动。 |
| 衣服与穿搭 | 所有来源均允许一比一复刻，包括现成整套服装；不为了证明设计量重新做丑衣服。图库缺少适配款式时允许查找网上公开参考，现代与古风均适用。 |
| 配饰、装饰、色卡与配色 | 可以直接提取、复用或重新组合。插画尤其用于特色配饰、特别发型、撞色、色阶和衣服搭配。 |

娃娃和二维脸可直接用，真人和AI脸须按框架调整；这是脸部的差别，不影响真人/AI图片里发型和衣服的一比一复用。类型拿不准时先核对图片和来源，不能凭文件名或导航标签宣称已鉴定；不确定的脸按框架调整处理。

一张综合图可以多用，也可以结合两张或更多适配图片，重新安排其脸、妆、发、衣、饰与配色。以组合协调、符合身份气质并且帅或美为准，不要求为每个部位做变化。用户锁定的白发等保留；不得机械交换发色瞳色冒充设计。瞳色仍仅在用户主动要求时处理，不能因为直接提取一张脸就自动复制其特殊瞳色。

允许复用图库素材，不等于连续角色固定使用同一张脸。先确认新角色或旧角色重做，两者均根据最新要求选参考设计新脸，用户明确保留的部分除外。但默认一次三版候选时，三张脸必须明显不同，不能只靠换装、换发或加痣凑三版。先按沟通流程确认头部或整套。仅整套模式每版配一套衣服，共三套；头部模式不设计衣服，用户另有指定时遵从。

记录选用图号、直接保留的部分、真人/AI脸的调整点，以及不同来源怎样组合。交付按本轮范围写成简短自然的提示词，不把“看图”“同参考”当作可见细节。实际生图若用了图片输入，说明该图的作用；带图复现不能冒称证明纯文字提示词已独立有效。

完整造型中相互依赖的款式、饰品和配色应整体保留，不能机械拆分后硬拼。允许好看的款式迁移到另一套色系，或将好看的色卡应用于另一款服装；迁移时重新分配部位、面积、明暗与装饰呼应，检查整体协调。整套适配时可以直接提取衣服、配色及妆面。
