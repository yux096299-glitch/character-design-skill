# 配色、公开色卡与合理撞色

## 本轮实际查看后再选色

每次设计先完成全库逐张查看，再实际分析适配的插画及人物三视图等综合图：主辅色、冷暖、色阶、明度纯度差、面积、邻接与穿戴部位的呼应。不规定只有两三色；多彩角色按其人设组织整套颜色，少色同样必须配得好看。衣服、发型发饰、妆容共同衬托人物，不能各配一套再硬拼。资料中的色卡是设计方法参考，不是直接搬整套人物的配色衣饰。

## 来源不限本地图

用户明确允许在使用技能时寻找外部色卡和搭配方法。用户提供的图是重要参考，但不是颜色选择的唯一来源。可以使用公开配色工具、不同国家与时期的服装与艺术设计、历史衣料、漫画动画角色设定、工作室或创作者发布的配色过程资料。按本角色需要检索，不要求每次遍历国家或年代。

只引用实际找到并查看的公开资料，不编造“某漫画工厂内部色卡”或把欧洲中世纪、美国、日本各自概括成一种统一配色。历史资料可启发色彩关系；用户未要求历史还原时，以角色好看为最高目标。

可用公开入口：

- [Adobe Color 色轮](https://color.adobe.com/create/color-wheel)：探索颜色关系与组合。工具结果只是候选，不自动等于适合本角色。
- [Adobe Color 色卡探索](https://color.adobe.com/explore)：查找公开色卡，实际使用时记录具体色卡页面或可复查的来源。
- 官方博物馆馆藏、服饰品牌展示、动画游戏官方设定图及设计者公开作品：实际查看具体作品后提取关系，不只靠名词联想。

## 合理撞色的目标

撞色是允许的设计手段。用户想要的是配在一起吸睛、锦上添花的组合，不是颜色越多、反差越强越好。不能因为自己不熟悉某个搭配就一概排除，也不能因为它符合色轮关系就直接宣称好看。

围绕本角色已定的发色、肤色观感和衣物结构考虑整套效果。瞳色仅在用户主动要求且已经确定时参与搭配，不能从参考图或身份自行派生。先形成主体色，再安排辅色、对比点和过渡；颜色数量与面积按实际造型决定，不机械套固定比例。

对比可以来自不同色相，也可以来自明暗、纯度和材质。两种鲜明颜色相遇时，检查哪一个占主导、在哪里相邻、是否需要中性色或金属色过渡、是否在另一个小部位呼应。用内外层、衣领袖缘、腰带、发束或配饰等明确载体组织色块，不把色卡所有颜色平均铺满全身。

不以“蓝和红一定不配”“紫和蓝不能同用”等色名组合做绝对禁令；同样不凭“互补色”三个字证明效果。具体颜色的明度、饱和度、面积和落位才构成实际方案。用户明确排斥某个组合时遵从。

## 给用户能判断的选择

用户未定配色或希望有惊喜时，主动提出少量完整搭配，例如一组协调美型方向和一组更吸睛的合理撞色方向；差异要落实到具体颜色及部位。用户已定颜色时，以该颜色为锚点补齐搭配，不擅自更换；从资料学习搭配方法，不整套搬用某张参考人物的色块和衣饰组合。

每组交代：发色与挑染、主要服装基色、内层/边饰、配饰颜色，以及撞色焦点在哪里、为什么衬托这个人物。只有用户主动要求瞳色且已经选定时，才额外列出虹膜配色。需要精确色卡时附色名和目标HEX；HEX是选色目标，最终提示词仍要写可理解的色名和部位，不让生图模型仅靠编码判断颜色。

最后检查：脸是否仍是适当的视觉重点，衣服是否与头部相称，撞色是否有主次，是否符合人物身份气质，是否因颜色堆砌而显乱或显俗。不好看就调整具体色调、面积或载体，不以“大胆创新”作为保留理由。没有生成图时，只称为配色提案，不声称已经验证出图效果。
