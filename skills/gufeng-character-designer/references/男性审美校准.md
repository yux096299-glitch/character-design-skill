# 男性脸部审美参考

[M001 男性审美基准](../assets/综合参考/M001-用户认可男性审美基准.png) 是用户给出的美貌参考之一，不是所有角色的统一脸型或发型。该AI人物脸参考框架后调整，发型与衣服按资源权限复用。

每轮按主技能完成全库查阅，优先比较适配的男娃脸与清晰正脸，再结合真人、明星、AI人物和二维插画。娃娃与二维脸、妆面允许直接提取；真人与AI脸须保留新的面部差异。观察整脸组合，不凭名字或记忆硬编。

关注眉眼走向与开合、面颊到颧颌的衔接、鼻唇的形状和相称关系，以及发顶、刘海和鬓发怎样衬托脸。不能把圆眼、尖下巴、小鼻、薄唇或浓眉当作每个男性的固定配方，也不反向一律禁止这些特征。

温柔、清冷、少年感通过全脸协调体现；允许适度理想化和少量娃感，不因真人逻辑限制动漫美术设计。妆面参考适合男性的娃娃或清晰人像，精致而不过重。最终用少量直白描述写清外貌，遵守本轮头部或整套的选择，不加入渲染设置。
